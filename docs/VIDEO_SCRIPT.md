# 30-second video

The finished video is `VIGIL-30s.mp4` in this folder: 1280 by 720, 26 seconds, with on-screen captions and a
synthetic voice-over generated with ElevenLabs text-to-speech (voice "Adam", model eleven_multilingual_v2). The
picture is screen recordings of the live app at https://tigertay0.github.io/vigil/ using the simulated crew.
Because the voice is AI-generated, the file's metadata says so (title, comment and description tags), the end card
says so on screen, and the project page's AI-use field names ElevenLabs.

Voice-over as recorded:

1. At Mars' farthest, help from Earth is forty-eight minutes away.
2. Space Vigil shows each astronaut what needs attention.
3. Every number is judged against your own baseline.
4. Each alert explains itself and says what to do.
5. Feel alert but test slow? Trust the test.
6. A real 2012 NASA solar storm turns the crew red.
7. Try it at the link.

Mars' farthest"), and line 5 says the test can flag the mismatch rather than claiming it catches sleep loss.
