# .design: design working notes

Notes kept while the interface was being designed and reviewed. They are not needed to run or judge the app.

| Item | What it is |
| --- | --- |
| `brief.md` | The design brief: users, direction, screens and rules for the interface |
| `design-system.md` | Colours, type, spacing and the shared components |
| `picks.md` | The directions and components chosen from the reference boards |
| `loop-log.md` | The review rounds and their scores |
| `rounds/` | Each round's checklist, review findings and verification notes |
| `scout/` | The reference board used to choose a direction |
| `edits/` | Batches of small interface tweaks |

For the project as a whole, see [../README.md](../README.md).
